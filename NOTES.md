# SpeedBike - notes for agents
Spec: BRIEF.md. Static ES modules, no build; Three.js 0.160 via importmap in index.html. Run: `python -m http.server`, open localhost:8000. Test: `for t in tests/*.test.mjs; do node $t; done` (physics, rules, ai, match, abilities, abilities2, save, modes, progression, controls, cloudsave, social, party).

## Modules (js/)
- `config.js` - ALL tuning (`CFG`): `tile` (grid tile = bike length), camera, `minTurnGap`, `match` (win points, round time, countdown), `players` (name/color), `ai` (difficulty + per-level params).
- `state.js` - `createState()`, `createBike`, `resetBike(b,spawn,speed)`, `spawnPoints(n)` (S,W,N,E on the axes, 0.8*half from center, facing center), `newSegment`. Pure data.
- `physics.js` - pure (no three). `step(state,dt)` moves bikes, grows newest segment, sweeps collision, returns `[{victim,killer}]` (killer null = fell off the map / side hit; no walls exist any more); same-tick hits kill both and clear the victim trail. `turnBike(b,side)`; `canTurn(b)` = newest segment >= `minTurnGap` long.
- `abilities.js` - pure (config + nothing else; physics registers `hooks.startBoost/startJump` to avoid an import cycle). See Abilities (phase 6).
- `rules.js` - pure scoring: `resolveTick(aliveBefore, crashed, rng)` (random surviving opponent point per crash, last-alive point, wipe = nobody), `resolvePlayerOut(aliveBefore, crashed, playerId, rng)` (player crashed: round ends now, one random surviving bot scores, nobody if no bot survives the tick), `resolveTimeout`, `applyAwards`, `matchWinner`, `placements` (display order), `rankings(scores)` -> `{id: rank}` competition ranks (ties share, 5,3,3,0 -> 1,2,2,4).
- `modes.js` - `MODES` registry (`standard`, `hyper`, `3d`, `deathmatch`; see Modes & maps) and `createMatch(state, mode, rng, hooks)`: phase machine countdown -> running -> roundEnd -> countdown|matchEnd (Death Match: countdown -> running -> matchEnd); `setMode/startMatch/startRound/advance(dt)/onTick(events,dt)/clock()/bonusCoins(id)`. `pickRespawn`. No DOM.
- `maps.js` - pure map data + `groundAt`, `terrainProbe`, `mapOf(state)`. See Modes & maps.
- `ai.js` - pure. `freeDist` ray lookahead, `aiThink(state,bike,ai,rng)` -> -1/0/+1, `updateAIs(state, ais Map, tickNo, rng)` (staggered: think when `(tick+offset)%every==0`). Level 2 (hard) adds coarse-grid flood fill (`buildGrid/floodArea`) for dead ends and cutting in front of the player. `makeRng(seed)` for tests.
- `input.js` - key/pointer -> 100 ms buffered turn queue; `popTurn(now, ready)` (ready=false keeps entry queued, used for min turn gap); `setOnPause` (Esc/P). `<button>` and `[data-ui]` targets are ignored by tap-turn.
- `render.js` - see Render architecture below. `textures.js` - procedural CanvasTextures (circuit wall, trail gradient). `audio.js` - see Audio below.
- `hud.js` - DOM HUD: score bar (player), timer, pause/resume, minimap canvas, countdown / round result / match result overlays (`syncOverlays(match)` polled each frame, DOM only touched on change). `save.js`/`menu.js` - see Menus and save (phase 5).
- `main.js` - bootstrap, 120 Hz accumulator; per tick: if phase != running -> `match.advance`; else player turn (gap-gated) -> `updateAIs` -> `step` -> bursts -> `match.onTick`. Pause = skip ticks.

## Data model
Bike: `{id,color,x,z,y,dx,dz,speed,alive,trail[]}`; dir is a unit axis vector. Segment: `{x1,z1,x2,z2,y0,h,owner}` occupying heights [y0,y0+h] (missing y0 = 0); last in `trail` is the growing one. Bike also has `baseSpeed, airTurn, boostMeter/boosting/boostLeft, jumpMeter/jumpT (-1 = grounded), boostsUsed, jumpsUsed` (counters reset every round by `resetBike`; read them at round end before the next round if achievements need them). Collision skips own newest segment; otherwise `segBlocks(y,s)`: bike occupies [y, y+bikeHeight(1)] and hits iff it overlaps [y0,y0+h] (strict). So a grounded bike passes under a segment with y0 >= 1 and a bike at y >= y0+2 passes over. There are NO walls: every map edge is a drop (see Playtest round 1).

## Boost / jump (phase 3)
- Config: `CFG.boost {mult 1.5, duration 1.5, recharge 6.5}`, `CFG.jump {height 3.5, rise .425, float 0, fall .425, recharge 5, trailStep .25}` (parabola, see Playtest round 1), `bikeHeight`, `ai.jumpTrigger/boostLook`, per-level `jump`/`boost`.
- physics.js: `startBoost(b)` (only with full meter; one-shot 1.5 s burst, meter drains 1->0 then refills linearly over 6.5 s from burst end), `startJump(b)` (grounded + full meter; meter 0 instantly, refills over 5 s from takeoff), `jumpY(t)` (ease-out rise, ease-in fall; `float` is 0 now = smooth parabola), `isAirborne`, `segBlocks`. `step` runs abilities first, then starts a new trail segment (before moving, like a turn) when |y - newest.y0| >= trailStep or on landing (so grounded trail is y0=0): ~30 segments per jump.
- No turning mid-air: `canTurn`/`turnBike` refuse unless `b.airTurn`; main drops buffered turns while airborne. Landing re-applies the 1-unit min turn gap.
- Input: Shift = boost, Space = jump (`pushAction/popAction`, 100 ms buffer, consumed per tick); HUD buttons `#boostBtn`/`#jumpBtn` use `pointerdown` and are `<button>`s so tap-to-turn ignores them. `hud.setAbilityButtons(bike)` shows fill % / "OK!!" / active glow.
- AI (`aiAbilities`): normal/hard jump when no open side and a trail (not the arena wall) is within `jumpTrigger`; boost with a per-think chance when >= `boostLook` units are free ahead. Easy neither.
- Render: trail meshes placed at y0 + h/2; `v.fin` tracks finalized segments (several can finish per frame). Camera rises 0.6*y during jumps. Minimap unchanged (shows all segments in 2D).

## Render architecture (phase 4)
- Pipeline: `WebGLRenderer` (DPR capped by `CFG.render.maxDpr`) -> `EffectComposer` (RenderPass, UnrealBloomPass, OutputPass; HalfFloat target, `bloom.msaa` samples) built lazily. `setBloom(strength)` (exported; settings hook): 0 = composer bypassed, plain `renderer.render`; >0 builds composer if needed. Values in `CFG.render.bloom`. Resize/orientationchange re-apply DPR + composer size.
- Materials are all `MeshBasicMaterial` (no lights); glow = colour multiplied >1 (`glowColor`) so it clears the bloom threshold. Floor: plane with a mipmapped/anisotropic grid CanvasTexture (`makeGridTexture`, 10x10 cells per tile, dim minor lines + brighter tile borders, kept near the bloom threshold) and an `onBeforeCompile` distance fade to black (`CFG.render.grid` fadeNear/fadeFar/gain). Walls: circuit CanvasTexture (generated once, seeded rng, tiles every 12 units), cloned per wall for its repeat.
- Bike model: primitives (dark hull, glowing belt/nose/lights, 2 wheels = tire + glowing torus rims + spokes that spin, leaning rider with helmet). Local +z = forward.
- Trails: ONE `InstancedMesh` per bike (unit box, per-bike material with gradient texture: bright edges, dimmer core). Capacity starts 256, doubles when needed (`growTrail`). Per frame only instances from `v.fin` (first non-final) to newest are rewritten into `instanceMatrix.array`, with a partial `addUpdateRange` upload. Round reset detected via `trail[0]` identity. Crash: bike's trail array empties; view keeps the old instances and drops `mesh.scale.y` to 0 over `CFG.trailFade`, then count=0. 4 bikes => 4 trail draw calls regardless of jumps. Physics segment count is NOT capped (jump segments still ~30 each; the minimap draws all of them every 3rd frame).
- Crash fx: pooled `InstancedMesh` (`CFG.burst.pool` fragments, typed-array state, swap-remove, shrink+dim fade, instanceColor) + 6 pooled additive flash spheres. `burst(x,z,color,y)`; `resetEffects()` clears everything at round start.
- Camera: yaw eased with `1-exp(-4/cameraSwing*dt)` (frame-rate independent, ~0.15 s), height smoothed with jump, FOV widens by `camera.fovBoost` while `boosting`. Player dead -> damped chase (`camera.spectate.follow`) of first surviving bike (sticks to it while alive); nobody alive -> slow orbit around arena centre. `resetCamera()` on round start.

## Audio architecture (phase 4)
- `audio.js`, WebAudio only. `initAudio()` (main) unlocks on first pointerdown/keydown/touchend; all sfx are no-ops until the context is `running`. Buses: music/sfx -> master -> compressor. API: `setMasterVolume/setMusicVolume/setSfxVolume(0..1)`, `setMuted(bool)`, `getVolumes()`, `setPaused(bool)` (game pause; context also suspended when tab hidden), `startMusic/stopMusic`, sfx `turn boost jump crash(loud) countdownBeep goBeep roundWin roundLose`, `setEngine(active,speed,baseSpeed,boosting)` each frame (player hum: saw+square through lowpass, pitch/filter follow speed ratio and boost).
- Music: look-ahead scheduler (setInterval 40 ms) of a 4-bar A-minor loop at `CFG.audio.bpm` (kick, hat, snare, bass 8ths, 16th arp, pad). Stops on suspend, restarts on resume.
- main.js hooks: turn/boost/jump at the action, crash on step events, countdown/GO/round stingers from phase changes in `trackAudio()`.

Progression: `coinsForPlacement` (`CFG.rewards.coins` [100,50,25,10]), `addSessionStats`, `recordMatch(placement)`. Add new save fields in `defaults()` (merge handles old saves); bump VERSION only for breaking changes.
- `menu.js`: DOM screens `#scrMain / #scrMode / #scrSettings` inside `#menu` (`data-ui`, so tap-to-turn ignores it). `showScreen(name|null, 'home'|'dim')`, `applySettings()` (save -> render setBloom/setMaxDpr, audio volumes/mute, HUD name), `initMenu({onPlay,onRestart,onQuit})`. Quality = DPR cap via `CFG.quality` and `render.setMaxDpr`. AI difficulty chosen on the mode screen (saved as `settings.aiDifficulty`, AIs rebuilt at `startGame`). Pause panel buttons (Resume/Restart/Settings/Quit) live in index.html; settings opened from pause stack above it (Esc/Back returns to pause).
- `main.js` flow: `screen` = 'menu' | 'game'. Player tallies (`session`: kills via `e.killer === playerId`, distance, boosts/jumps counted at the action) are committed to the save at round end, match end, quit, restart, page hide - so per-round counter resets don't lose anything. Match end: `recordMatch(placement)` once (`rewarded` flag) -> `hud.setMatchReward` -> results show coins earned/total + Play again / Main menu. Quit/restart mid-match counts no match. - Input: keydown ignored while typing in INPUT/SELECT; Esc in menus backs out. HUD name via `hud.setPlayerName` (textContent); result HTML escapes names.
- Placements: `match.ranks[id]` (shared on equal points; coins = that rank's amount; shared 1st counts as a win). `match.placements` is only a display order. All four modes unlocked (phase 7); Garage/Stats screens = phase 8.

## Abilities (phase 6)
- Config `CFG.abilities`: `maxSlots` (3) and per-ability `{price, cooldown, duration, ...}`; `CFG.ai.loadouts[level]` (Hard = turbo+protector), `turboLook/turboChance/chasedDist`. Turbo: mult 2.5, duration 125/37.5 s (~125 u at base 15; fixed seconds, so Hyper covers more), cooldown 15 s counted from activation. Cooldown ticks on the physics step (pause/countdown freeze it); round reset = everything ready.
- `abilities.js`: `ABILITIES` registry `{id,name,short,icon,type,desc,price,cooldown,duration,once,onActivate(b,state),onTick(b,dt),mods}` (numbers via lazy getters from CFG). ids: turbo fastCharge rocketJump doubleJump airTurn protector stealth slowDown allBoost allJump. API: `setLoadout(b,ids)` (drops unknown/dupes, caps slots, sets `airTurn`), `useAbility(b,state)` (active slot; onActivate returning false = refused, no cooldown), `useAbilityId` (AI), `cycleAbility` (skips passives), `canUse/onCooldown/isActive/isProtected`, `speedMult(b)`, `modOf/boostDuration/jumpRecharge/canDoubleJump`, `tickAbilities`.
- Bike fields: `abilities[]`, `activeAbility`, `cd{}`, `active{}`, `used{}` (once-per-round), `slowLeft`, `stealth`, `boostDur`, jump arc `jumpH/jumpTS/jumpY0/jumpDur/djUsed`. `resetBike` clears timers but keeps the loadout (main sets loadouts in `startGame`: player from save, AIs from config).
- Physics: speed = `baseSpeed * max(boostMult, turboMult) * slowMult` (recomputed only while a modifier is/was active, so tests can still poke `b.speed`). `startJump(b, {height,timeScale})` for Rocket; airborne + Double Jump = one extra jump per airtime (arc restarts from current y, +3.5). `jumpY(t,H,ts,y0)`. Protector: `hit()` skips trails (falling still kills). Slow Down slows the user's OWN bike (`slowLeft`, 0.6x for 4 s; stacks with boost). All Boost/All Jump force others (meter refilled; airborne bikes skip All Jump), once per round. Stealth: `b.stealth` while active; minimap hides it for non-player viewers, dims the player's own dot.
- Input/HUD: E = ability, Q = swap (pushAction 'ability'/'swap'), `#abilityBtn` hexagon (clip-path in a drop-shadow wrapper), `#swapBtn` beside the right chevron (hidden unless >= 2 active abilities equipped), `#chevL/#chevR` lit 160 ms by `hud.flashTurn(side)` on a player turn. `hud.setAbilityHud(bike)` (cache-keyed). All are `<button>`/pointer-events none so tap-to-turn ignores/passes correctly. Camera FOV widening and engine pitch follow `speed > baseSpeed`, so Turbo shows too.
- Save: `unlocks.abilities` (free ones always present), `equipped.abilities` (<= maxSlots, must be unlocked); `clamp` validates against the registry. `buyAbility(id)`, `toggleEquip(id)`. Old saves without `equipped.abilities` get the free abilities; explicit [] stays empty. ABILITIES screen `#scrAbilities` (main menu, beside Settings).
- AI (`aiUseAbilities`, Hard only): Turbo with >= `turboLook` free ahead and (opponent right behind or `turboChance` per think); Protector when boxed in by a trail (not the wall) and jump not ready. `freeDist` ignores trails while protected; `aiThink` scales its danger distance by speed/baseSpeed (earlier turns while boosted/Turbo).

## Modes & maps (phase 7)
- Config: `CFG.hyper.speed` 25; `CFG.deathMatch {lives 3, respawnDelay 1.5, spawnProtect 1.0, coinsPerKill 5, samples 200, margin 6}`; `CFG.gravity` 45; AI level `gap` chance.
- `MODES[id] = {id,label,kind:'rounds'|'deathmatch',map,speed(getter),roundTime,winPoints,onCrash,onTimeout,countUp}`. `hyper` = standard at 25 u/s; `3d` = standard rules on map `tiers`; `deathmatch` = lives. `match.setMode(mode)` then `startMatch()` sets `state.map = MAPS[mode.map]`. main: `startGame(modeId)` (restart / play again reuse `modeId`); menu buttons carry `data-mode`.
- `match.runTime` (s since GO, used for the "GO!" overlay) and `match.clock()` (HUD timer: count-up elapsed for Death Match else timeLeft).
- **Death Match** (`tickDeathMatch`): `lives{}`, `kills{}` (= `scores`), `respawnIn{}`, `outAt{}`. Crash event -> life lost; kill credited to `e.killer` unless null/self; lives left -> respawn after `respawnDelay` via `pickRespawn` + `resetBike` (full meters, abilities ready) + `b.spawnProt = spawnProtect` (trails can't kill it; walls/falls still do; 0 disables) + `hooks.onRespawn`; no lives -> out for good. Ends when <= 1 bike has lives (even if that bike is dead waiting to respawn). Ranks: winner 1st, then by elimination time desc (same tick shares a rank; ties for last survivors -> shared 1st, most kills named winner). Coins: `recordMatch(rank, match.bonusCoins(id))` = `CFG.rewards.coins[rank-1] + kills*coinsPerKill`. `pickRespawn`: `samples` random points on platforms (area weighted, `margin` from edges/walls), maximise min distance to alive bikes and ALL trail segments (tie: nearer centre), face the axis with most open `probe` distance. HUD: top-left bar = lives (`hud.setBarSegments(n)` + `setPoints`), `#status` line ("RESPAWN IN 1.2" / "ELIMINATED - SPECTATING"); spectate = existing render logic (follow a survivor / orbit) while the player is not alive; `onRespawn` resets the camera. No rounds / roundEnd.
- **maps.js**: map = `{id,name,walls,half,killY,platforms:[{x0,z0,x1,z1,y}],spawns|null}`. `MAPS.arena` is the default (getter reads `CFG.arena.half`: one 102x102 platform y=0, no walls, spawns on the axes); `MAPS.tiers` is the 3D map. `groundAt(map,x,z)` = highest top containing the point (inclusive edges) or -Infinity; `terrainProbe` marches a ray and reports 'void' | 'drop' | 'high'. `state.map` (createState default arena) is read by physics, AI, render, hud minimap. Add maps there + a mode `map` key.
- **TIERS** (no walls, half 90, killY -14): MAIN 78x78 at y=0 (spawns radius 28); EAST/WEST 48x48 pads at y=2, 3-unit gap from MAIN (x 42..90; jump peak 3.5; take-off in the last ~7.5 units before the edge works = 0.52 s window, measured by a sweep in modes.test); NORTH/SOUTH 60x30 low decks at y=-2 glued to MAIN's z edges (driving off drops 2 and survives; climbing back needs a jump). Open edges drop; gaps and the far sides are void = crash. Max climb ~2.6 (peak 3.5), AI `findLanding` max gap 8.
- **STAIRS** (half 60): square ring of four 24-wide strips around a void at y 2.25 / 1.5 / 0.75 / 0 (N, E, S, W, travel clockwise); driving off a strip end drops onto the next; the last (W) ends against the first (N) side: jump climbs it (window 2.75..10.25 units = 0.52 s). **BIG HOLE** (`crater`, half 63): flat 126x126 with a 78x78 hole (24-wide ring). Maps per mode: `mode.map` may be a list; `startMatch` picks one with the match rng (standard + deathmatch: arena/crater/stairs, 3d: tiers/stairs, hyper: arena); online clients use `start.mapId`.
- **Height physics** (`physics.js`): bike fields `y, falling, vy, jumpG` (ground at takeoff = where the arc ends), `justLanded`, `spawnProt`. `step`: `updateAbilities` (arc sets y) -> new trail segment if y drifted >= trailStep or just landed -> move -> `settle()` per bike. `settle(b,map,yPrev,dt)`: ground `g` under the new point; `g > yPrev + 0.05` -> fatal `'side'` (side of a higher platform; also running onto a pad below its top); jump arc lands when it comes down onto `g`; arc end -> `falling` with the arc's end speed (lands at once on same-level ground, otherwise gravity); grounded + ground gone -> `falling`; `y < map.killY` -> fatal `'void'`. Events for these carry `cause` ('side'|'void', killer null); wall/trail events have no `cause` key. `isAirborne` = arc or falling (no turn, no jump); `jumpY(t,H,ts,y0,yEnd)` falls to `yEnd`. Arena walls: only when `map.walls`; fatal at any height. Protector / spawnProt skip trails only. Trail y0 follows b.y so segments sit on whatever platform the bike is on.
- **Render**: `buildMap(map)` (rebuilt when `state.map` changes) = per platform a dark box slab (grid-textured top clone with fade shader, dim circuit-board sides, glowing cyan frame on the top edges; no wall meshes). Orbit camera radius scales with `map.half`. Minimap draws platforms (shade by height) then trails/dots, scale from `map.half`.
- **AI**: all distances (look, maxLook, jumpTrigger, boostLook, turboLook) scale by `ratio = max(1, speed/CFG.baseSpeed)` (so Hyper keeps the same time-to-impact); think interval divides by `baseSpeed/15`. `probe(state,b,dx,dz)` -> `{d,kind}` (kind wall|trail|void|drop|high|max) replaces raw `freeDist` (kept as a wrapper); walled single-platform maps skip the terrain march (exact old behaviour). Edges/higher sides count as obstacles, flood fill is per level (`buildGrid(state,y)` marks cells whose ground isn't at the bike's level as blocked). Gap crossing: facing a void/high hazard with jump ready, `findLanding` (landing platform <= 2.6 higher, 7+ units of room) -> roll `level.gap` once per approach (always when boxed in) -> `ai.crossing` keeps it straight and `aiAbilities` jumps when the edge is within 3*ratio units. Trail box-in jumps require `jumpLandsSafely` (ground ~1.2*speed ahead).

## Playtest round 1 (no walls, tiles, instant round end, jump arc)
- **No borders.** `MAPS.arena.walls = false` (102x102, `CFG.arena.half` 51); render has no wall meshes (platform slabs keep circuit-board sides + glowing cyan top frame); minimap draws no wall box. Driving off an edge = `settle()` starts `falling` (gravity 45, keeps its heading/speed) and crashes at `map.killY` (-14) with `{killer:null, cause:'void'}` after ~0.8 s. `walls` is still a legacy physics flag (off everywhere). AI: `probe` now runs `terrainProbe` on the arena too (edge = 'void'), flood grid blocks off-platform cells. Render: a falling bike pitches nose-down and rolls (visual only, `v.fall`), camera sinks slowly and looks down at the bike (`cam.fall`). Death Match respawn margin 9 (3 tiles) from edges.
- **Tiles (scaling approach).** Physics units are unchanged (speeds, sizes, trail height, camera, AI distances: the game feels the same in seconds). `CFG.tile = 3` world units = one bike length; the bike model is scaled to it (`bikeScale` 1.1 -> wheel-to-wheel ~2.97). Floor grid texture = 4x4 tiles with ONE line per tile border; each platform's UVs are offset so lines sit on multiples of `CFG.tile` in world coordinates (every platform shares the grid). Platform sizes are whole tiles (arena 34x34, TIERS main 26x26, pads 16x16, decks 20x10). Positions are free: nothing snaps to lines/centres (spawns, turns keep fractional coordinates; test in modes.test).
- **Player death ends the round (Standard/Hyper/3D).** `roundMode.onCrash` -> `resolvePlayerOut` when the player is among `crashed`; `match.lastResult.reason = 'out'` (or 'draw' when no bot survives), `match.delay = CFG.match.playerOutDelay` (1.5 s) then next countdown / matchEnd (5 points). Bot-vs-bot crashes while the player lives keep `resolveTick`. HUD title "YOU CRASHED". Death Match untouched. `match.playerId()` exposes `state.playerId` to mode policies.
- **Jump arc.** `CFG.jump {height 3.5, rise .425, float 0, fall .425}`: symmetric parabola, 0.85 s in the air (12.75 u at base speed), peak 1.75x trail height; bike is above trail height (y >= 2) for 0.56 s => take-off must be 2.2..10.5 units (0.14..0.71 s) before a trail (swept in abilities.test; too early lands inside it, too late hits it). Rocket (7, x1.4 time) and Double Jump (restarts from current y) work unchanged. TIERS gaps: pads at y=2 (= trail height), gap = 3 units (one tile), take-off window 0..7.5 units before MAIN's edge = 0.52 s (modes.test sweep asserts 0.45..0.65 s); decks y=-2 glued to MAIN, climbing back needs a jump from 2.1..10.6 units before the edge. AI: `jumpTrigger` 5 units = 0.33 s inside the window; `jumpLandsSafely` now also refuses when another trail crosses the landing stretch (78%..100% of the arc length ahead); `findLanding` maxW 8.

- Netcode (all bikes run the SAME deterministic sim locally at the estimated server tick; no AI):
  - Tick clock: every ev / snap / round / crash carries the server tick; `TickClock` keeps the max of `tick - recvMs*hz/1000` over a window (= least delayed sample) and adds RTT/2. `advance()` steps the sim up to that tick (also called at the top of ev / snap / crash handlers so they compare with a world that is "now"). Non-running phases only move the counter (server ticks also during countdown).
  - Own inputs: popTurn/popAction at each local tick -> `predictInput` (applies it, tags the trail segment `pred`) and `{t:'in', kind, side, ctick}` is sent at once; kept in `sim.pending` until the server's `ev` for it arrives (or 180 ticks pass).
  - `ev` (state right BEFORE server tick T): rewind that bike (drop segments with `ct > T`, restore the scalar state saved for tick T from `sim.hist`, own bike also drops its `pred` segments and consumes the matching pending input), put the head at the authoritative state, start boost/jump, re-apply the still-pending own inputs, then re-simulate THAT bike alone (collides with its own trail only) forward to now. `respawn` ev = fresh bike + trail (Death Match). So trails are exact: every segment carries `ct` = creating tick.
  - Lag compensation (server `Room.#applyRewound`, see docs/MULTIPLAYER.md "Lag compensation"): the server applies an input at its `ctick` (rewind that bike from a 48-tick history ring, apply, replay alone to now, cap `CFG.net.maxRewindMs` = 150 ms) and the `ev` carries that tick. So the authoritative turn point equals the predicted one: own-bike correction ~0 (measured, virtual-time sim with the real Room: 0.000 u at 60/150/250 ms RTT, was 0.7 / 1.9 / 3.2 u; beyond the cap only the excess x speed). Replay collision uses other bikes' trails as of each replayed tick (not "now"); a crash after the claimed tick is final.
  - Visual smoothing (render only): every correction (`ev`, `snap`) keeps the old displayed position as an offset `b.vox/voz` (`visCapture`/`visBlend`/`visDecay` in netsim.js) that decays with tau = `CFG.net.blendMs`/3 (120 ms ~ 95%); render.js adds it to the bike mesh + camera and the along-heading part to the trail head. Sim and trail geometry stay exact. Own bike: errors > `blendOwnMax` (3 u) or a changed heading snap; remote bikes blend across their late turn up to `blendRemoteMax` (10 u).
  - Client fixes found with the latency sim: a prediction the server applied later than its ctick (past the cap / future ctick) now also undoes the prediction's jump/boost effects from before the press; an input pressed on the exact tick an earlier `ev` is replayed up to is re-applied (was lost); a snap does not revive our own locally-crashed bike while one of our inputs is in flight (the server may kill it on replay).
  - HUD: `#ping` under the timer shows the latest ping RTT (`ClockSync.last`; dim, yellow > 120 ms, orange > 220 ms; `?ping=0` or `CFG.net.showPing=false` hides it). `online.dbg` counters: snaps/corrected/revived/events + ownEvents/ownErr/ownErrMax/remoteErrMax/smoothed/snapped.
  - Server loop: ONE `setInterval` of 16 ms (was 4 ms) runs the due 120 Hz ticks (catch-up unchanged), lobby timers, rotation, heartbeat; snapshots still 10 Hz. `/health` has `loop` (wake-up spacing, cpuPct) and `roomStats[]` (avgMs/maxMs per update, ticks behind, lagComp counters).
  - Latency tests: `server/test/lagsim.mjs` (virtual-time link between the real Room and 4 client sims, jitter, ordered delivery) used by `server/test/lag.test.mjs` (60/150/250/400 ms RTT, random bots, abuse cases) and `tests/net.test.mjs`; `server/test/e2e-lag.test.mjs` = full real-socket 4-client match at 150 ms RTT +-20 (real time, ~25 s; env `E2E_RTT_MS`/`E2E_JITTER_MS` work on `e2e.test.mjs` too).
  - `snap` (10 Hz): server state projected forward to our tick; bikes off by > `CFG.net.snapEps` (0.35 u) or with another heading are corrected (slide along the axis, else new trail segment from the authoritative head); a bike alive on the server but dead here is revived with a fresh trail; own bike is skipped while an input is in flight. Local crash detection plays the burst at once; `crash` only kills bikes still alive. In a loopback test the snap error is ~0 for all bikes.
  - `round`: countdown -> bikes placed at `spawnPoints` (same as modes.js) and sim reset; running -> `sim.tick = msg.tick`; roundEnd keeps the overlay; the final panel waits for `end` (ranks). Timer = server `roundTime` + local ticks since.
